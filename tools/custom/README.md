# Custom Tools

Добавляй свои инструменты в этот каталог как JSON-файлы.

Формат файла (массив объектов):
```json
[
  {
    "name": "имя_инструмента",
    "category": "observe|control|create|analyze",
    "description": "Что делает инструмент (одна строка)",
    "command": "bash-команда для выполнения"
  }
]
```

Инструменты из этого каталога автоматически подхватываются при старте Монады
и инжектируются в системный промпт Тела (Body).
